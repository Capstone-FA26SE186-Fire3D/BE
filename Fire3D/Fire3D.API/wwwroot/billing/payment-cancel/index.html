Bạn đã rời trang thanh toán

URL cancel không thay đổi trạng thái trong database. Nếu muốn hủy link, gọi API POST /api/payments/payos/requests/{id}/cancel với Bearer và Idempotency-Key.

Kiểm tra API trạng thái trước khi thanh toán lại. Giao dịch hợp lệ đã nhận vẫn được ghi nhận qua webhook kể cả khi bạn trở về bằng URL cancel.
